# B04：面试证据包任务与测试计划

> 分支：`agent/b04-interview-demo`
>
> 基线：`agent/b03-quality-observability`
>
> 状态：待开始

## 1. 目标

让面试官在五分钟内看懂业务价值、技术深度、失败兜底和验证证据，并确保简历表达与真实代码一致。

## 2. 实现任务

- [ ] 重写 README：定位、架构、核心流程、快速启动、验证命令、限制和演进。
- [ ] 增加架构图、Tool Calling 时序图和人工兜底说明。
- [ ] 增加稳定、可重复的演示账号与演示数据。
- [ ] 建立 AI 意图离线评估集和可重复执行的评估脚本。
- [ ] 输出准确率、转人工召回率等实际评估结果，禁止手写虚假数据。
- [ ] 增加 3～5 分钟演示脚本。
- [ ] 增加面试高频追问及基于代码的回答。
- [ ] 增加简历项目表述和 STAR 版本，但不伪造线上业务指标。
- [ ] 增加已知限制、技术债和下一阶段决策标准。
- [ ] 校正文档中与实现不一致的意图、工具、流式和部署描述。

## 5. 完成定义

- 新读者只根据 README 可以启动并理解核心流程。
- AI 质量数字来自仓库内评估命令。
- 演示和面试回答均能定位到代码、测试或审计数据。
- 最终分支基于前三批提交并独立推送。
